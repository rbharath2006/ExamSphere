# Online Examination System

A full-stack web application for conducting and managing
online examinations.

## Technology Stack

- Java 25
- Spring Boot 4.1.2
- React + TypeScript
- PostgreSQL 18
- Spring Data JPA
- Spring Security
- Maven
- Git and GitHub

## Modules

- Admin Management
- Teacher Management
- Student Management
- Examination Management
- Question Management
- Evaluation and Results
